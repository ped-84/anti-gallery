# آرت‌گشت — Art Gasht

مسیریاب گالری‌گردی تهران: نمایشگاه‌های جاری را انتخاب کن، آرت‌گشت بهترین ترتیب بازدید را با توجه به ساعات گالری‌ها و ترافیک تهران می‌سازد.

- لایو: https://artgasht.com (آینه‌ی ایران: https://artgasht.ir)
- React 19 · TypeScript · Vite · Tailwind v4 · Express · Docker · نقشه‌ی نشان

## اجرا

```bash
npm install
cp .env.example .env   # مقادیر را پر کنید
npm run dev            # http://localhost:3000
```

## مستندات

- [`PROJECT_HANDOFF.md`](PROJECT_HANDOFF.md) — معماری، قوانین، گردش کار، مشکلات شناخته‌شده
- [`DEPLOY.md`](DEPLOY.md) — راه‌اندازی و استقرار سرورها
- [`CLAUDE.md`](CLAUDE.md) — قوانین کوتاه برای دستیار هوش مصنوعی
